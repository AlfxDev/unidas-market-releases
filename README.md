# Unidas Market — Descargas

Aplicación de compras de barrio para Colonias Unidas. Hablás directo con los comercios por WhatsApp: no hay pagos dentro de la app.

**Solo Android por ahora.**

## Descargar la última versión

👉 https://unidasmarketweb.vercel.app/descargar

## Cómo instalarla

1. Tocá el enlace de arriba desde tu celular Android.
2. Abrí el archivo descargado y, si Android lo pide, permití "instalar apps desconocidas" para tu navegador.
3. Si aparece el aviso de Play Protect, tocá "Más detalles" y después "Instalar de todos modos".
